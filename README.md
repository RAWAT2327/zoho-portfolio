# Everflow ↔ Zoho CRM Integration

## Project Overview

Implemented an integration between **Everflow Affiliate Management Platform** and **Zoho CRM** to synchronize partner/affiliate information, manage partner applications, and automate the partner approval/rejection process.

The integration connects Everflow partner data with custom Zoho CRM modules and automates key partner-management workflows.

## Key Work Completed

- Integrated **Everflow with Zoho CRM** using APIs and webhooks.
- Configured Everflow webhooks to send new partner signup information to Zoho CRM.
- Created and configured the **Pending Applications** custom module in Zoho CRM.
- Mapped Everflow partner information into Zoho CRM fields.
- Integrated Partner Manager information from Everflow into Zoho CRM.
- Mapped Everflow Affiliate ID between Everflow and Zoho CRM.
- Implemented Referral ID handling for new partner applications.
- Created a **Referred By** field to display referral information entered by the applicant.
- Created a **Referred By Link** field to link the application to the corresponding Zoho Account when a matching referral Account exists.
- Implemented Account lookup using the Everflow Affiliate ID rather than Account Name.
- Added handling for applications where no Referral ID is provided.
- Added handling for cases where referral information is entered manually by the applicant.
- Tested partner signup data with and without Referral IDs.
- Implemented automatic Account and Contact creation when a partner application is approved.
- Configured automatic linking between the newly created Account and Contact.
- Implemented Everflow partner approval/rejection actions directly from Zoho CRM.
- Developed a custom **Reject Application** button using Deluge and Everflow API.
- When an application is rejected from Zoho CRM, the integration updates the corresponding Everflow partner status.
- Updated the Pending Application status to **Rejected** after successful rejection.
- Automatically added a **Rejected** tag to the Pending Application using the Zoho CRM Tags API.
- Implemented error handling and response logging for Everflow and Zoho CRM API operations.
- Troubleshot OAuth scope, API, webhook, field mapping, and CRM automation issues.
- Tested the complete partner signup → Pending Application → approval/rejection workflow.
